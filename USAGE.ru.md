# USAGE — OpenCode Session Manager

[English](https://github.com/EnerJizeIT/opencode-session-manager/blob/master/USAGE.md) · [README](https://github.com/EnerJizeIT/opencode-session-manager/blob/master/README.ru.md)

## Что даёт

Сохраняй важные opencode-сессии — а шум пусть чистит сам.

- **Не потеряешь** важную сессию: закрепи, забэкапь, восстанови в любой момент.
- **Автоочистка** старых сессий (бэкап → удаление; закреплённые всегда защищены).
- Работает **через чат**: просто скажи, что нужно — агент вызовет нужный tool. Команды учить не надо.

## Тебе ли это

Да, если у тебя много opencode-сессий и хоть раз ты: терял ценный разговор, не мог найти нужную сессию или хотел, чтобы старые убирались сами.

## Старт за 30 секунд

Ты просто говоришь агенту обычным языком — он вызывает нужный tool и сам понимает, о какой сессии речь (текущая, из контекста, или найдёт). Три вещи закрывают 90% повседневного:

1. **Закрепи то, что важно сохранить** — «запинть эту сессию» → она защищена от очистки.
2. **Посмотри закреплённые** — «покажи закреплённые» → список + готовая строка `opencode -s <id>` для каждой.
3. **Вернись в нужную** — скопируй `opencode -s ses_…` из списка и вставь в терминал.

> **Нужна конкретная старая сессия?** Скажи «найди сессию про X» или дай ID (узнать: `opencode session list` в терминале).

## Ежедневные

| Ты говоришь | Что произойдёт |
|---|---|
| «запинть эту сессию» | защищена от очистки |
| «открепи её» / «открепи закреплённые про X» | убрана из закреплённых |
| «покажи закреплённые» | список + `opencode -s <id>` для возобновления |
| «найди сессию про платёж» | совпадения по названию; pinned помечены `*` |

## Безопасность: бэкап и восстановление

| Ты говоришь | Что произойдёт |
|---|---|
| «сделай бэкап этой сессии» | сохранена в `backups/` + подсказка как восстановить |
| «забэкапь все закреплённые» | сводка: N сохранено, M failed |
| «восстанови сессию из бэкапа» / «восстанови вчерашнюю» | импортирована; `force=true` для перезаписи |
| «полный бэкап для переноса на другую машину» | архив: сессии + state + плагин + RESTORE.md |

**Типичный кейс:** бэкапь перед рискованным изменением; восстанавливай, если сессия пропала.

## Обслуживание (настроил и забыл)

| Ты говоришь | Что произойдёт |
|---|---|
| «покажи настройки» / «статус» | настройки + счётчики сессий и бэкапов одним взглядом |
| «включи автоочистку через 30 дней» | старые незакреплённые бэкапятся и удаляются |
| «ротация старых бэкапов» | удаляет устаревшие; pinned/orphaned всегда защищены |

После включения автообслуживание запускается **раз в час** (по следующему
вызову любого tool плагина, debounce 1 ч) — без ручной работы. Весь вывод CLI
заглушён; за один прогон чистится не более **50 сессий** (остальные ждут
следующего прогона — терминал не захламляется).

**Pinned Guarantee:** закреплённые сессии никогда не удаляются cleanup'ом, их
бэкапы обновляются раз в `pinnedBackupRefreshDays` (по умолчанию 7), а если
закреплённая сессия исчезла из БД — она **автоматически восстанавливается** из
своего бэкапа и логируется в `session-manager-hooks.log`.

Ключи настроек: `autoCleanupEnabled`, `autoCleanupDays`, `backupRetentionEnabled`,
`backupRetentionDays`, `backupDir`, `pinnedBackupRefreshDays`.

## Только терминал (без чата)

```bash
# Закреплённые (ID + title):
jq -r '.pinned[] | "\(.sessionId)  \(.title)"' ~/.local/share/opencode/session-manager.json
# Доступные бэкапы:
ls ~/.local/share/opencode/backups/
# Восстановить из бэкапа и открыть:
opencode import ~/.local/share/opencode/backups/ses_xxx.json
opencode -s ses_xxx
```

Другие полезные команды: `opencode session list` (все сессии + ID), `opencode -s <id>` (возобновить), `opencode export <id>` (ручной экспорт).

## Где что лежит

- State (список закреплённых + настройки): `~/.local/share/opencode/session-manager.json`
- Бэкапы: `~/.local/share/opencode/backups/`
- Хранится вне БД opencode → переживёт переустановку.

## Все tools (справочник)

| Tool | Что делает |
|---|---|
| `sm_status` | сводка одним вызовом: счётчики, бэкапы, кандидаты, последний прогон |
| `sm_pin` / `sm_unpin` | закрепить / открепить сессию |
| `sm_list` | закреплённые + команды возобновления |
| `sm_search` | поиск по названию (или названию + note) |
| `sm_backup` / `sm_backup_all` | бэкап одной / всех закреплённых |
| `sm_restore` | восстановить из файла бэкапа |
| `sm_list_backups` | список доступных файлов бэкапов |
| `sm_full_backup` | полный архив для переноса |
| `sm_settings` / `sm_config` | посмотреть / изменить настройки |
| `sm_cleanup` | бэкап + удаление старых незакреплённых (партиями по 50, dry-run по умолчанию) |
| `sm_cleanup_backups` | ротация старых бэкапов (dry-run по умолчанию) |
| `sm_cleanup_pinned` | убрать записи о закреплённых, чьих сессий больше нет |
